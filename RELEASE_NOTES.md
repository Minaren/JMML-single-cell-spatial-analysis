# Release notes: v1.0.0

Release date: 2026-08-31

This is the first citable release of the analysis code associated with the
Treg-IL-10-CD69 study in Kras-driven JMML. It includes mouse HSPC and T-cell
scRNA-seq, human JMML scRNA-seq, survival analysis, BMKMANU S1000 spatial
transcriptomics, RCTD deconvolution and communication visualisation scripts.

## Data accessions

- GSE313553: mouse c-Kit+ HSPC scRNA-seq from 6-week-old mice
- GSE313878: mouse bone-marrow spatial transcriptomics
- GSE313879: NB4 CD69-overexpression bulk RNA-seq
- GSE111895: public JMML dataset
- GSE155259: public normal pediatric bone-marrow dataset
- GSE71449: public JMML expression and clinical dataset
- GSE122465: public mouse bone-marrow reference dataset

Full execution was not performed during packaging because the complete inputs
and matching R environment were unavailable. See `CODE_VALIDATION.md`.
